# TMA4422 Matematikk 3C — Kræsjkurs Vår 2026

153 sider håndskrevne notater laget til Teknas kræsjkurs i Matematikk 3C ved NTNU. Bygget av Bilal Sheikh basert på åpent tilgjengelige øvinger, flervalgsoppgaver og innleveringer fra faget — uten å ha tatt kurset selv.

## Innhold

- **Lineær algebra** — ligningssystemer, nullrom/kolonnerom, lineærtransformasjoner, ortogonalitet, Gram-Schmidt, egenverdier, diagonalisering og Cauchy-problemet
- **Numeriske metoder** — integralbroen, Euler/Heun/RK4, Butcher-tabellen, lokal avbruddsfeil og metodeorden
- **Rekker** — konvergenstester, potensrekker med konvergensintervall, Taylorrekker og standardrekkene
